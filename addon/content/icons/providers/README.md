# Provider icons

These provider SVGs are vendored from [Lobe Icons](https://github.com/lobehub/lobe-icons), package `@lobehub/icons-static-svg` version 1.91.0.

Lobe Icons is Copyright © 2023 LobeHub and distributed under the MIT License. Brand names and logos remain trademarks of their respective owners.

Provider icons are loaded as external images. Monochrome SVGs therefore use an
explicit black fill instead of `currentColor`, whose user-agent value changes
with Zotero's color scheme. The surrounding icon style supplies the appropriate
background and inversion.
